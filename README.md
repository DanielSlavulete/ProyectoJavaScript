# Tienda de Componentes

Aplicación web Full Stack desarrollada con **JavaScript Vanilla** en el frontend y **Node.js** en el backend. El proyecto simula una tienda online de componentes electrónicos al estilo de plataformas como PCComponentes, permitiendo la visualización de productos, gestión de carrito y un sistema de usuarios con roles.

Este proyecto fue desarrollado con fines académicos para practicar la creación de aplicaciones web completas sin frameworks frontend, trabajando directamente con JavaScript puro y una API en Node.js.

---

## Features

### Cliente (User)

- Registro e inicio de sesión.
- Visualización de productos disponibles.
- Añadir y eliminar productos del carrito.
- Simulación de proceso de compra (sin pago real).
- Visualización del historial de pedidos.
- Consulta de datos de usuario y rol asignado.

### Administrador (Admin)

- Panel de administración de usuarios.
- Eliminación y gestión de usuarios.
- Creación, edición y eliminación de productos/componentes.
- Visualización de todos los pedidos realizados.
- Control completo del catálogo de productos.

---

## Architecture

### Frontend

- JavaScript Vanilla (ES6+)
- HTML5
- CSS3
- Fetch API para comunicación con backend
- Manipulación del DOM

### Backend

- Node.js
- Express.js
- API REST
- Gestión de usuarios, productos y pedidos

---

## Features Overview

- Sistema de autenticación de usuarios.
- Control de acceso basado en roles (Cliente / Administrador).
- Gestión de productos tipo e-commerce.
- Carrito de compra simulado.
- Historial de pedidos por usuario.
- Panel administrativo completo.

---

## Academic Project

Este proyecto fue desarrollado como parte de un trabajo académico del ciclo formativo de **Desarrollo de Aplicaciones Web (DAW)**.

El objetivo principal fue comprender los fundamentos del desarrollo web sin frameworks frontend, trabajando directamente con JavaScript Vanilla y construyendo una API en Node.js.

Durante el desarrollo se trabajaron conceptos como:

- Consumo de APIs REST desde frontend.
- Manipulación del DOM con JavaScript puro.
- Gestión de sesiones y autenticación.
- Control de roles de usuario.
- Arquitectura cliente-servidor.
- CRUD completo de productos y usuarios.
- Simulación de flujo de compra en una tienda online.
